# Contributing

1. Name files `packs/<app>-<yourhandle>.pikopack` (lowercase, hyphens).
2. Validate against `schemas/pack.v1.json` and `schemas/recipe.v1.json`.
3. Allowed step actions: `ring`, `click`, `hotkey`, `scroll`, `wait`.
4. Add one entry to `index.json` under `packs`.
5. Open a pull request.
